# Bulk Certificate Generator

A Flask-based web application that generates multiple certificates in bulk from recipient details.

## Features

- Generate certificates automatically
- Generate multiple certificates at once
- Store certificate information in a database
- Download generated certificates as PDF files
- REST API for certificate generation
- Simple and easy-to-use Flask backend
- Certificate validation and testing support

## Technologies Used

- Python
- Flask
- SQLite
- ReportLab
- REST API
- HTML/CSS
- Git & GitHub
